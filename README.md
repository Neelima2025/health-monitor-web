---

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/health-monitor-web.git
```

2. Navigate to the project directory

```bash
cd health-monitor-web
```

3. Install dependencies

```bash
npm install
```

4. Run the application

```bash
npm start
```

5. Open in browser

```
http://localhost:3000
```
